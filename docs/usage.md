# 使用指南

[返回首页](../README.md) · [安装与更新](install.md) · [开发指南](development.md)

## 连接与基础操作

推荐双击 `mwb-v0.5.9-windows-x64.msi`，点击「安装」并确认管理员授权。完成后打开 MWB Rust，或使用桌面快捷方式。后续更新继续运行新版本 MSI；卸载在 Windows「设置 → 应用 → 安装的应用」中操作。详见 [安装与更新](install.md)。

首次打开只显示「作为主机 / 连接主机」初始化页面。成功配对后直接进入设备画布；再次打开、停止连接或断线重连时均保留画布。顶部可添加设备和暂停共享，设置与传输记录按需从侧边面板打开。

1. 所有电脑运行本程序。一台持续在线的电脑选择「作为主机」，使用自动生成的配对密钥，也可输入自定义口令。
2. 点击「创建主机」，作为连接中心；在顶部「添加设备」查看并复制主机地址、端口和配对密钥。允许本程序通过专用网络防火墙：控制端口默认为 TCP **24810**，可在初始化的「高级设置」修改；文件/剪贴板使用中心协商的动态 TCP 端口。只开放 24810 时可能出现键鼠可用而数据通道未连接。
3. 其他电脑选择「连接主机」，填写中心的 IP 或主机名与相同密钥，点击「连接并记住」。最多 16 台设备（含中心），加入后自动显示在画布上，无需每两台电脑重复配对。
4. 拖动屏幕调整设备位置。一台电脑的多块屏幕作为一组移动，保留 Windows 中的实际相对位置。「+ / −」缩放，中键拖动画布，「适应画布」显示全部设备。
5. 点击「保存布局」同步到所有设备。屏幕重叠会提示并拒绝保存；允许任意偏移及空隙。「还原」撤销未保存的拖动。
6. 鼠标移过屏幕边缘时，沿当前移动方向有其他在线屏幕则切入，否则停留在当前设备。可以从本机切到 B，再从 B 切到 C，也可返回本机。
7. 选中画布中的设备后，浮动操作条提供「控制设备」、发送剪贴板和文件发送入口；底部「传输记录」可查看进度与接收文件邀请。
8. **Ctrl + Alt + Home** 紧急暂停并返回本机。接收端操作自己的物理键鼠会接管控制，之后仍能重新切入。

首次配置完成后，下次在各电脑打开程序即可恢复工作组，无需重新输入密钥或点击创建/加入。先打开加入端也可以，保持「自动重连」开启，中心上线后会自动连接。

如需重启后自动运行，在各电脑的「设置」开启「开机自启动」，并保持「启动时自动连接」开启。这里的开机自启动发生在**该 Windows 用户登录后**，会显示正常窗口；关闭窗口会退出程序，本次不再共享，下次登录仍会启动。尚不支持首次登录前恢复工作组或托盘运行。Windows 可延迟启动应用，若在系统「设置 → 应用 → 启动」或任务管理器禁用了 MWB Rust，请先在系统中允许。

连接中心转发经过认证的消息，需保持运行。所有设备都可作为控制端；同一时刻只有一个远控会话，新的控制请求接管会话并释放旧目标按键。多端同时修改布局时，过期草稿会被拒绝并提示重试。

## 自动剪贴板与文件

自动剪贴板默认开启：连接并开启共享后，新复制的文本、图片和文件列表会同步到所有在线设备。可以在「设置」关闭；手动「发送剪贴板」仍可发送文本或图片到选中设备。不会主动发送连接前的剪贴板。接收写入会标记并去重，避免反复同步；传输期间本机新复制的内容优先于旧的在途内容。

**跨设备粘贴：** 两端保持连接、开启共享与自动剪贴板。在 A 的资源管理器选中文件，按 Ctrl+C；切到 B，在目标文件夹按 Ctrl+V（或右键「粘贴」）。粘贴即发起下载，无需再点击「接收」。多文件、中文文件名和空文件均支持；目标目录及重名询问由 Windows 处理。使用共享键鼠控制 B 或在 B 本机操作均可。源端 Ctrl+X 在远端按复制处理，不删除源文件。

复制时只同步名称与大小，不提前下载到所有电脑。粘贴时先下载到接收端临时目录，校验成功后交给 Windows 写入目标文件夹；可在本程序的传输列表查看下载进度、取消或调整限速。大文件下载期间资源管理器进度可能暂时停在准备阶段。本程序显示「已校验，交给 Windows 完成粘贴」后，最终保存结果以资源管理器为准。

同一份文件再次粘贴会复用已校验的缓存。正常释放剪贴板及粘贴对象后清理缓存；接收端临时盘和目标盘均需足够空间（同盘时需要额外一份文件空间）。源文件复制后变化、源端离线、剪贴板被更新时，新下载会拒绝或失败，请重新复制后粘贴。进程异常退出可能在 `%TEMP%\MWB-Rust-clipboard` 留下缓存。

仍可使用「选择文件发送」或「发送剪贴板中的文件」。这些定向发送需要对方点击「接收」，保存到界面设置的「接收文件夹」，同名自动改名。该目录设置不影响 Ctrl+V 的目标目录；收到的文件不会自动运行。

**不设置文件大小上限**，文件大小和偏移均使用 64 位整数；实际容量受磁盘空间和文件系统约束。每批及待发送队列最多 64 个文件，这是任务数量限制。发送期间请勿修改源文件。文件完成后验证 SHA-256，再将临时文件提交为最终文件。取消、连接中断或校验失败会清理临时文件；暂不支持断点续传，需重新发送。

默认限速 **8 MiB/s**，可选 1、4、8、16、32 MiB/s 或不限速，每台设备的发送、接收方向分别按所有数据通道的总量限制。中心转发也限速；较慢的一端会形成反压。若无线网络上鼠标不够流畅，可调低到 1 或 4 MiB/s。键鼠使用另一条连接、线程和队列，不受文件的队列拥塞直接阻塞。

暂停共享停止键鼠与自动剪贴板，并移除本程序提供的远端文件剪贴板；已经开始的文件传输可以继续，也可单独取消。「停止连接」取消所有传输。目前支持普通文件，不发送文件夹、HTML 或富文本；仅接受文件路径的应用可能不支持原生虚拟文件粘贴。文本最多 16 MiB，图像 RGBA 最多 128 MiB；这些限制不适用于流式文件。

## 尺寸与自由位置

画布按 **实际分辨率比例** 显示，不使用英寸或 Windows UI 缩放后的逻辑尺寸。例如 3840×2160 屏幕的画布宽高均为 1920×1080 的两倍。屏幕方向、负坐标、多屏间隙来自 Windows 显示器枚举；同一电脑内部的排列在 Windows 显示设置中调整。

自由位置使用统一像素坐标，允许负坐标。跨屏时沿移动方向寻找最近相交的在线屏幕，跳过设备间的空白，在目标边缘略微内缩落点。右侧偏下的设备只有在移动方向与它相交时才会进入。

离线设备仍显示并保留位置，不参与切换。保存布局会先结束当前远控，避免坐标变化时误点击。屏幕信息在程序启动时读取，改变分辨率或插拔显示器后目前需要重启程序刷新。

在连接中心选中离线设备，点击浮动操作条中的「移除离线设备」图标即可释放设备名额，并同步到在线成员；请先保存或还原未保存的布局。停止连接后也可清理本机记录，重新加入时以中心的列表为准。不能移除本机或在线设备；列表已变化时请刷新后重试。移除只清理布局记录，持有相同密钥的设备仍可重新加入。

## 共享偏好与恢复

- 相对移动鼠标：默认关闭。关闭时按控制端主屏与目标桌面的分辨率比例缩放位移；开启时使用原生相对移动，通过目标实际光标位置反馈判断跨屏。两端无需设置一致。
- 屏幕边缘切换：默认开启；关闭后仍能手动选择设备。
- 边缘切换条件：默认「直接切换」，也可选择「按住 Ctrl」或「按住 Shift」。左右键均可；仅使用控制端设置，关闭共享键盘时仍有效。切入远端后松开按键会阻止后续自动跨屏，但不会中断当前控制；再次按住并移动即可继续切换。手动控制和 Ctrl + Alt + Home 紧急返回不受条件限制。
- 角落避让：默认关闭；控制端避免在每块屏幕四角的 100 物理像素区域切换。
- 自动重连：默认开启，加入端按 1、2、4、8、16、30 秒间隔重试中心，最长保持 30 秒；中心持续监听，每条新连接重新握手。
- 开机自启动：默认关闭，仅作用于当前 Windows 用户。开启时登记正在运行的程序位置，关闭时移除本程序的启动项；开关开启表示启动项已登记，实际运行仍受 Windows 启动应用设置控制。程序位置变化后会提示启动项指向其他位置，可重新开启或关闭，普通启动不会自动更改登记。安装版建议在安装目录的程序中开启；便携版移动或删除前先关闭，再在新位置重新开启。自启动项不含密钥、配对信息或开发配置路径。
- 启动时自动连接：默认开启，恢复上次成功创建或加入的工作组。关闭后仍记住密钥，可手动创建/加入；与断线后的「自动重连」分别设置。「停止连接」只停止本次运行；停止后点击「忘记配对」清除本机保存的连接，下次打开不再自动连接。
- 共享键盘：跟随当前鼠标目标；关闭前结束远控并释放按键。
- 剪贴板：自动同步文本、图片和文件列表；文件由对端粘贴触发下载，手动发送的文件需要对端点击接收。

正常断线释放按键，重连恢复待命；手动暂停、紧急返回和注入失败后的暂停会保留。注入和系统剪贴板写入失败保留连接并显示错误。协议错误终止相关连接，旧协议在握手阶段被拒绝。

「停止连接」取消等待和握手；TCP 建连单地址最多等待 3 秒，主机名解析耗时由系统决定。

## 配对与保存

默认生成 64 位十六进制随机密钥；也支持 1–64 个字符自定义口令和自定义随机长度。去除首尾空白，自定义口令区分大小写。原有 64 位十六进制密钥保留字节解释；其他口令使用 Argon2id（版本 0x13、19 MiB、2 次迭代、并行度 1、域盐 mwb-rust/pairing/argon2id/v1）派生 PSK。

每条到中心的链路使用 Noise NNpsk0 / X25519 / ChaCha20-Poly1305 / BLAKE2s。中心是可信转发节点。短口令的强度低于随机长密钥。

设备标识、已保存布局、偏好、限速、接收文件夹及配对连接保存在 %LOCALAPPDATA%\MWB-Rust\settings.json。密钥使用当前 Windows 用户的 DPAPI 加密，并绑定本机设备标识，不以明文保存；每台电脑分别完成一次配置，**不要复制整份配置到其他电脑或 Windows 账户**。设置通过同目录临时文件替换，避免直接截断旧配置。创建端监听成功、加入端经认证并收到有效工作组布局后才记住新连接；失败的尝试保留原配对。无法解密时显示错误，保留记录并等待手动重新配置，不自动更换密钥。忘记配对只清除本机记录；禁止旧设备再次加入需在工作组所有设备更换密钥。旧左右配置不再约束自由布局。开发可用 MWB_CONFIG_DIR 指定隔离目录。

## 锁屏控制（可选接收端服务）

标准 MSI 安装已包含输入服务，安装后可从另一台电脑操作被控端的 Windows 锁屏和管理员窗口，控制端保持解锁。从桌面快捷方式运行安装版即可。

使用开发/便携版时，也可先构建，再在被控端的**管理员 PowerShell** 中执行：

    cargo build --release --locked
    powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\input-service.ps1 -Action Install

安装后打开 **`C:\Program Files\MWB-Rust\mwb.exe`**（以实际 Program Files 目录为准），输入配对密钥并创建或加入工作组，然后再锁屏。必须运行安装目录里的程序；服务会校验客户端路径和登录会话。MSI 安装的版本继续使用 MSI 更新；旧脚本安装可直接升级为 MSI，升级后通过 Windows 设置卸载。

服务只处理接收的键鼠输入，不保存配对密钥、不处理剪贴板或文件，也不自动打开主程序；重启后仍需先登录，可由「开机自启动」打开主程序并恢复已保存的工作组。服务中断会释放控制并保留网络连接，恢复服务后在被控端重新开启共享。MSI 卸载或旧脚本的 `-Action Uninstall` 均保留用户配置和接收文件；不要对 MSI 安装目录运行旧脚本卸载。

尚未完成两台实体电脑的锁屏登录验收；自动测试覆盖桌面切换状态、输入服务通信、按键释放和故障恢复。完整安装、诊断、权限范围与验收步骤见 [锁屏输入服务](input-service.md)。

## 当前边界

尚无自动发现、自定义快捷键、文件夹传输、断点续传、跨设备直接拖放及托盘。主程序自启动发生在用户登录后。可选服务仅支持当前物理控制台会话的接收端输入，不支持锁屏控制端捕获、首次登录前配对、RDP 会话或远程 Ctrl+Alt+Delete；UAC、多用户切换及复杂多屏仍需实机验收。中心离线时暂停远控，尚无自动中心选举。画布不改变单机内部 Windows 显示设置。最多保存 16 台设备，可移除离线设备后腾出名额。所有注入使用标准 SendInput。
