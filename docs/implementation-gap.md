# 与原版逆向结果的实现对照

更新日期：2026-11-06。当前实现：Rust v0.5.0，线协议版本为 5。

## v0.5.0 更新

跨设备 Ctrl+V 文件粘贴已实现。复制时只同步名称和大小，目标电脑在资源管理器粘贴时通过原生 OLE 虚拟文件流请求正文；目标目录和重名处理由 Windows 负责。支持多文件、空文件、中文名称、按需下载、取消重试、磁盘缓存复用和源文件变化检测。沿用独立加密通道、可调限速与 SHA-256 校验，无固定文件大小阈值；远端粘贴始终复制，不删除源文件。

已通过原生 COM 跨线程流测试、Windows Shell 实际异步接收，以及 128 MiB 原生剪贴板流的三设备转发。文件夹、跨设备直接拖放、断点续传及真实多机 Ctrl+C/Ctrl+V 验收仍需后续推进。详见 [剪贴板与文件设计](clipboard-files.md)。

## v0.4.0 更新

自动同步文本与图片，并提供关闭开关、去重、版本顺序和本机新复制保护。文件可以多选发送，或从资源管理器复制后点击发送剪贴板文件；接收端选择目录并同意接收，提供进度、取消、摘要校验和同名保护。

原版 Common.cs 的 MAX_CLIPBOARD_FILE_SIZE_CAN_BE_SENT 为 104857600，剪贴板文件路径据此拒绝超过 100 MiB 的文件，并提示改用拖放；不能据此推断所有原版传输入口都使用同一限制。新版流式文件不设该大小阈值，使用 64 位长度和偏移。已实际完成 128 MiB 文件的三设备加密转发及 SHA-256 校验。

数据使用独立 Noise/TCP 通道、线程和有界队列，默认每设备每方向总限速 8 MiB/s，可调低或取消限速。慢接收端形成反压；键鼠不经过文件队列。详见 [剪贴板与文件设计](clipboard-files.md)。

## v0.3.0 更新

多设备和布局已按用户要求实现为自由画布，不复刻原版四机矩阵：最多 16 台设备按实际分辨率等比例显示，可任意拖动、错位摆放与留空隙；多屏内部位置保持 Windows 设置。保存后共享布局，跨屏按几何位置路由。中心转发支持任意设备互控及跨第三台设备连续切换。

新增稳定设备 ID 与布局持久化、布局修订冲突检查、会话编号输入路由，以及三设备真实 TCP/Noise 回环测试。详见 [自由布局设计](free-layout.md)。下表已更新为 v0.5.0 状态；原先的四机矩阵建议由自由画布方案取代。

仍需补齐：实机 DPI/多屏/组合键及文件粘贴验收、屏幕信息热更新、自动发现、密钥持久化、文件夹、断点续传、托盘、自启动、Windows 服务与安全桌面。历史网络格式与私有注入 API 继续不复刻。

对照对象是本地 Microsoft Garage Mouse without Borders **2.2.1.0327** 的离线静态分析，不代表当前 PowerToys 版本，也不把静态代码当作双机实测结果。原报告对照的 Rust 版本是 v0.1.2；其中关于两种鼠标模式的建议已在 v0.2.0 实现，不能继续列为缺失。

## 保留的设计差异

- 仅重写版之间互联，继续使用 Noise NNpsk0 / X25519 / ChaCha20-Poly1305 / BLAKE2s，不照搬原版固定布局和 AES-CBC 通道。
- 所有键鼠注入使用标准 `SendInput`。v0.2.1 已验证私有 `InjectMouseInput` 在本机失败；不为了 API 名称一致重新引入该入口。
- 原版多屏绝对坐标采用手工变换；本版把屏幕比例映射为目标物理像素，再使用 ABSOLUTE | VIRTUALDESK 定位。这是语义重建，不能宣称已经取得所有多屏条件下的等效手感。
- 密钥不持久化仍是明确边界。自动重连不会在程序重启后找回旧密钥，也不会自动连接其他已保存设备。

## 恢复与连接边界

连接重试只使用用户本次「加入工作组」输入的中心地址。间隔为 1、2、4、8、16、30 秒，之后保持 30 秒；成功的设备握手重置间隔。每次连接创建新的 Noise 状态。中心不会把客户端临时源端口当成对方监听端口。

暂停意图与当前连接是否能共享分开记录：正常断线重连后恢复待命；手动暂停、紧急返回、输入注入失败、发送队列拥塞均保留暂停。明确再次点击「停止连接」后重新发起连接属于新的一次配对运行，按原有行为自动启用共享。离线切换布局或偏好不再被误认为发送队列拥塞。

可识别的认证、帧格式、协议错误停止主动重试，具体错误留在连接记录。TCP EOF、超时等网络错误可重试；对端提前断开不能证明密钥不匹配。被动监听仍保留，错误的未认证入站连接不会修改主动重试计划。

握手强制使用阻塞 socket + 100 ms 轮询超时，并设置总计 3 秒的期限；连接取消可在检查点生效，也限制逐字节拖延握手。正常会话继续使用非阻塞 IO。TCP 建连单个地址的超时为 3 秒，主机名解析由系统管理，暂不承诺这两个阶段能立即取消。

角落保护在物理坐标下判断，使用当前控制端的偏好，对本机发起切换、远端比例/相对移动的后续切换均生效。保护范围以每块显示器为单位；极小屏幕可能没有可切换的边缘中段，手动控制和紧急返回仍可使用。

## 后续优先级

1. **实机验收与输入体验**：三台实体电脑验证连续切换、双向比例/相对模式、125%/150%/200% DPI、负坐标和错列显示器、Ctrl/Shift/Alt 组合键；再实现按键条件切换。
2. **日常使用完整性**：受保护的配对持久化、托盘和关闭行为；文件夹、断点续传与异常退出缓存回收。自动文本/图片、跨电脑文件粘贴和独立限速传输已完成。
3. **设备管理**：屏幕信息热更新、离线设备删除、自动发现及更直观的连接状态；中心自动接管另行设计。
4. **系统集成**：验收可选锁屏接收服务；控制端安全桌面捕获、主程序自启动、首次登录前连接另行设计。仅用管理员启动窗口不能代替会话内代理。

## 验证与资料

本轮常规核心测试 58 项通过，另单独通过 Windows Shell 异步接收和 128 MiB 原生剪贴板流测试。新增按需粘贴、缓存复用、取消重试、源文件变化、剪贴板撤销、来源离线、COM 格式与 64 位描述符、跨线程封送、读取/Seek/Clone/EOF 测试。保留三设备真实 TCP + Noise 路由、布局、重连和输入故障测试。输入与剪贴板监测后端替换为测试桩，不安装全局钩子、不移动真实光标、不写真实剪贴板。

桌面自动化运行时存在 Windows 沙箱初始化故障，未完成资源管理器实际按键的视觉/点击验收。Shell 接口和加密回环测试不能替代实体多机、系统剪贴板和网络手感验收。发布构建、严格 lint 及隔离配置启动结果记录在发布包旁的验证清单中。
